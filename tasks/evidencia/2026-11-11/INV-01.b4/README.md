## Alcance por hijo

- **INV-01.b4.manual**, cuatro archivos: `app/api/inventory/sales-entry/route.ts`, `lib/services/sales-ingest-service.ts`, `tests/unit/inventory/sales-entry-access.test.ts`, `tests/integration/sale-consumption-application-db.test.ts`. Cantidad cero anula; cantidad e ingreso rechazan precisión excesiva y overflow antes del writer; ingreso ausente o NULL se conserva. Dinero se convierte por dígitos decimales, sin Math.round. Devuelve inserted/updated/skipped, cobertura y errores tipados 400/403/409. El GET legado no se acepta ni se amplía en esta fase.
- **INV-01.b4.bulk**, dos archivos: ruta bulk y `tests/unit/inventory/sales-entry-bulk.test.ts`. El rol ausente cae a EMPLEADO, no a ADMIN. El schema conserva productKey independiente de receta. La fuente explícita `pos:import` coincide con la subida POS del cierre, para que repetir el mismo origen por otra frontera no cree otra identidad. Los errores del parser impiden declarar revenueComplete global. El archivo sin grupos válidos devuelve 400 sin writer; alcance rechazado por runtime devuelve 403.
- **INV-01.b4.smartlink**, dos archivos: ruta upload-pos y `tests/unit/inventory/sales-entry-smart-link.test.ts`. Comprueba permiso inventory:manage, consistencia tenant/sesión y sucursal propia antes de ingerir o enlazar evidencia. JSON y multipart solo actualizan cortes de empresa/sucursal/día civil. Mapeo explícito prevalece sobre adivinación y conserva productKey. Errores y cobertura del parser se agregan a la respuesta del writer. JSON enlaza URL sin afirmar ingestión; multipart conserva advertencias si no puede generar ventas. Se mantiene el almacenamiento placeholder preexistente: no acredita almacenamiento durable ni aceptación del workflow.

El modo `atomic` de ingestión envuelve TODO el lote en un savepoint adicional; el primer error del plan o writer aborta ese lote. La importación CSV conserva grupos independientes y el writer único por grupo. La prueba SQL comprueba que el llamador puede capturar el error y seguir usando su transacción sin conservar la primera venta, identidad, revisión ni movimientos.
