## Comportamiento

La interfaz presenta grupos nuevos, corregidos y sin cambios por separado. Deja de etiquetar repetidos como actualizados y de afirmar que todo resultado descontó inventario. La cantidad es por producto/día, no por línea del archivo. Ingreso ausente se muestra como "No reportado" en la vista previa. `revenueComplete=false` muestra "Ingreso incompleto"; indicador ausente muestra "Cobertura de ingreso no disponible". Errores o cobertura no completa llevan a "Importación con pendientes", sin icono de éxito total.

Una respuesta HTTP 400 conserva `message` y errores por fila, en vez de descartarlos detrás de un error genérico. Listas largas de errores de vista previa y resultado pueden desplegarse completas. La vista previa no permite enviar si no quedan grupos válidos. Encabezados con comillas/comas usan `splitCsv`, el mismo lector del parser. El formulario permite mapear `productKey` (SKU) aparte de la receta y descarta mapeos guardados cuyas columnas opcionales ya no existan.

El formulario se deshabilita nativamente durante el envío. Archivo, sucursal, día o mapeo nuevos invalidan el resultado anterior. La lectura de archivo limpia los datos previos, muestra estado de lectura y descarta respuestas de lecturas anteriores si el usuario selecciona otro archivo. La región del resultado tiene nombre accesible y aria-live polite. La tabla móvil mantiene un ancho legible dentro de un contenedor desplazable, enfocable y operable con teclado; no desborda la página.
