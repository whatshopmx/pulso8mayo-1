#### Priority Issues

- **[P0] Data Filter Disconnect Bug in Top KPI Metrics**
  - **Why it matters:** Selecting a branch in `DashboardFilters.tsx` updates the URL query string, but `ComplianceMetrics` and `KpiSummaryCards` fetch global data without passing `branchId`. Multi-branch owners make decisions based on false metrics.
  - **Fix:** Pass `searchParams` (`branch`, `startDate`, `endDate`) as props to `ComplianceMetrics` and `KpiSummaryCards`, and forward them to the API.
  - **Suggested command:** `$impeccable harden app/dashboard`

- **[P1] Triple KPI Grid Fatigue & High Cognitive Load**
  - **Why it matters:** 3 separate 4-card grids (`ComplianceMetrics`, `ExecutiveSummary` alerts, `KpiSummaryCards`) create 12 stat cards on a single page, overloading working memory (17 decision points).
  - **Fix:** Consolidate into 1 top-level "Attention Required" banner and 1 executive summary row of 4 key metrics.
  - **Suggested command:** `$impeccable layout app/dashboard`

- **[P2] AI Slop & DESIGN.md Rule Violations (Side Stripes, Shadows, Hardcoded Colors)**
  - **Why it matters:** Announcement cards use 4px left accent bars (`border-l-4`), cards use `shadow-sm`/`hover:shadow-md` (violating Flat-By-Default), and display text uses `text-purple-600` and sub-ramp `text-[10px]` type.
  - **Fix:** Strip left accent bars, replace shadows with flat `border-border`, update purple/sub-minimum type to standard Geist OKLCH tokens.
  - **Suggested command:** `$impeccable quieter app/dashboard`

- **[P3] Broken Custom Date Filter Affordance**
  - **Why it matters:** 'Rango personalizado' runs `if (key === 'custom') return;` without launching a date picker dialog.
  - **Fix:** Trigger a modal date picker on selection or disable the option until ready.
  - **Suggested command:** `$impeccable clarify app/dashboard/components/dashboard-filters.tsx`
