## Anti-Patterns Verdict

**LLM assessment:** Not AI-slop visually — the flat OKLCH system, Geist, and warm neutrals are deliberate and documented. The tells are structural: (1) hero-metric card grids as the default section on nearly every dashboard (explicitly banned in DESIGN.md), (2) uppercase tracked section eyebrows inside product UI (`OPERACIÓN DIARIA DE PERSONAL`, 18 instances), (3) rainbow category colors (slate/red/purple/orange/cyan/green) that fight the One Voice Rule, (4) identical icon+heading+text card grids on labor. The inventory page is the exception — it has a real point of view (state → attention → start-the-day).

**Deterministic scan:** 5 findings, exit 2 — 3× `border-accent-on-rounded` (`border-b-2` on rounded cards: ai-verifications:215, equipment:267, equipment/[id]:226), 2× off-ramp font sizes (10px audit:840, 11px profile/onboarding:171). Low count, all legit; no false positives. Detector misses the systemic issues (token bypass, scaffolding drift) because they're cross-file patterns.

**Visual overlays:** Not available — no browser automation tool exposed this session; overlay injection skipped.

## Overall Impression

A well-intentioned design system being eroded by execution drift. DESIGN.md is strong (flat, tonal, One Voice red) and the newest surfaces (inventory, home attention queue, shared primitives) follow it. But half the dashboard predates or ignores it: three header patterns, palette colors everywhere, spinners over skeletons, and metric-stacked pages. The single biggest opportunity: consistency — make PageContainer/PageHeader + semantic tokens the only way to build a page, and the system quality jumps a full band.

## What's Working

1. **Inventory page information architecture** — state (KPIs) → attention (alerts) → action ("Empezar el día" strip) mirrors how a gerente actually opens their morning. Branch rollup badge, "Actualizado hace X" with a clarifying tooltip, and hover-reveal affordances show real craft.
2. **Home attention queue (PendingRemediationActionsCard)** — ranked pending-first, preview of 3 with "Ver todo (N más)" progressive disclosure, confirm dialog, and a proper "Todo al día" empty state. This is the command-center pattern the rest should copy.
3. **Resilience scaffolding** — `loading.tsx` with section skeletons, `error.tsx` with retry, `SectionErrorBoundary`, shared `EmptyState`/`KpiCard`/`PageHeader` primitives, complete dark-mode tokens, global reduced-motion handling.

## Priority Issues

- **[P0] Workflow creation sends a magic zero-UUID branchId** — `app/dashboard/workflows/page.tsx` `createInstance` posts `branchId: "00000000-0000-0000-0000-000000000000"` for every "Iniciar" and "Compartir" from the workflows dashboard. Instances get mis-attributed or fail silently. **Why:** data integrity in the core loop. **Fix:** resolve branch from `useBranch()`/session like execute/page.tsx does. **Command:** `$impeccable harden`

- **[P1] Three page-scaffold dialects; shared primitives adopted by a minority** — only 32/130 pages use `PageContainer`; 56 files hand-roll `text-3xl font-bold` h1s (PageHeader spec is `text-xl sm:text-2xl`); my-tasks, labor, workflows each invent their own header. **Why:** the product register's core promise is earned familiarity; right now each section feels like a different app. **Fix:** codify one scaffold (PageContainer + PageHeader + KpiGrid + EmptyState), migrate pages mechanically. **Command:** `$impeccable distill`

- **[P1] Raw Tailwind palette bypasses the semantic token system in 110 files** — `amber-600` solid buttons, `emerald-500` status, `yellow-500/10` badges instead of `--warning`/`--success`/`--info`. Amber — not Operational Red — has become the de-facto attention color; red is triple-loaded (brand, destructive, SAFETY category); status badges like `text-yellow-600 on bg-yellow-500/10` are dark-mode contrast risks. **Why:** breaks the One Voice Rule, makes theming cosmetic, risks illegible states. **Fix:** map status vocabulary to semantic tokens; reserve amber for warning semantics only. **Command:** `$impeccable colorize`

- **[P1] The navigation spine doesn't scale and isn't there on first paint** — ~60 destinations across 8 sections (Inventario alone: 22 links); no command palette/search; sidebar is `dynamic(ssr:false)` with a `hidden` fallback, so the command center renders with no navigation until hydration. **Why:** owners with 15 branches hunt; first-time users can't build a mental map; power users have no fast path. **Fix:** SSR the sidebar (or skeleton it), add ⌘K palette over the nav model, prune/pin top destinations per role. **Command:** `$impeccable layout`

- **[P2] Metric soup: dashboards stack KPI grids instead of making decisions obvious** — home: remediation card + ComplianceMetrics + ExecutiveSummary + KpiSummaryCards + 2 chart sections + recent activity + announcements (8 sections, 4 metric grids). Labor: ~28 data points, with attendance %, break %, and overtime each shown twice; "GPS Verificación: Activo" is a hardcoded fake status; the LFT legal-citation card is the bureaucratic anti-reference made flesh. **Why:** principle #1 says every screen makes the next decision obvious; these pages make every number equally loud. **Fix:** one decision per section; dedupe metrics; move legal reference behind a "Marco legal" disclosure. **Command:** `$impeccable distill`

## Persona Red Flags

**Alex (Power User)** — No ⌘K/command palette, zero keyboard shortcuts, no bulk actions (approvals, stock counts, remediation all one-at-a-time). `window.location.href` full-page reloads (my-tasks:30, equipment/catalog:89, overtime/requests:48) punish fast navigation. Sidebar absent until JS hydrates. He'll route around the UI within a week.

**Sam (Accessibility-Dependent)** — Status conveyed by color alone throughout (amber icon vs muted icon is the only signal in ExecutiveSummary alerts); raw-palette badges (`yellow-600`/`amber-600` on 10% tint) risk contrast failure in dark mode; `text-[10px]` micro-labels; 94 `animate-spin` instances with no evidence of `aria-busy`/live-region announcements; muted-foreground token is borderline ~4.5:1 on white.

**Mariana (multi-branch owner, project persona)** — Her morning brief exists but is fragmented: the attention queue is first (good), then three more metric sections before recent activity; chain-vs-branch rollup only works where pages read the cookie (inventory does, several older pages don't). She asked "which branch needs me?" — the dashboard answers with numbers, not a ranked branch list.

## Minor Observations

- `border-b-2` accent strips on rounded cards (3 files) — detector-flagged, clashes with radius.
- Off-ramp `text-[10px]`/`text-[11px]` literals (2 files) — below the label ramp minimum.
- `shadow-sm` on the remediation card — the system's only card shadow; flat-by-default says remove.
- Sidebar hardcodes Spanish titles while translating only the "Plataforma" group label; i18n infra exists (next-intl) but is used in 1/130 dashboard files — pick one strategy.
- my-tasks uses `console.log` for status-change feedback and routes via `window.location`; oldest-pattern page still linked in nav.
- "Pulso Intelligence", "Constructor KPIs", "Dashboard Ejecutivo" — three analytics-ish destinations whose differences aren't obvious from labels.
- LaborQuickActionDrawer + "Acciones Rápidas" card duplicate each other on the same page.
- 94 `animate-spin` vs 10 files using Skeletons — spinners are the dominant loading idiom despite skeleton primitives existing.

## Questions to Consider

- What if the home dashboard were a queue, not a report? "Here are the 4 things that need you today" with everything else one click down.
- Does every module need its own "Dashboard" page, or is that 8 home pages competing with the real one?
- If amber disappeared tomorrow and only semantic tokens remained, which screens would lose meaning? (That's the measure of token bypass.)
- What would the sidebar look like if each role saw 5 destinations, not 60?
